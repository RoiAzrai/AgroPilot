# Plot photo UI: design reference

These 3 files are the approved design for the AgroPilot frontend redesign:

- `Main.dc.html`: home page, desktop
- `Plot.dc.html`: plot page, desktop
- `PhoneA.dc.html`: phone layout, option A

## Reference only

They are **reference only**. They depend on `support.js` from the design canvas environment, so they cannot run here.

The implementation must copy the visual values from them: colors, sizes, spacing and copy text. The design tokens live in the files' inline styles.

Do not edit these files.
